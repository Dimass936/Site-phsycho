# PRODUCT_STRATEGY.md — Стратегия продвижения

## 1. Продукт в одном абзаце

Онлайн-консультации психолога Анастасии Палютиной — это профессиональная психологическая помощь для взрослых, пар и подростков, которая помогает справиться с тревожностью, наладить отношения, поддержать детей в трудные периоды и найти внутренний ресурс для изменений. Продукт существует в формате многостраничного сайта-визитки с блогом, который одновременно информирует, вызывает доверие и конвертирует посетителей в клиентов через удобную запись в мессенджерах. Главная ценность для клиента — безопасное пространство, где его услышат, и профессиональный подход без географических ограничений.

## 2. Целевая аудитория

### Родители (основной сегмент)

**Кто:** женщины 28–45 лет с детьми 4–17 лет. Живут в городах, активны в интернете.

**Что их беспокоит:** поведение ребёнка в школе, страхи, агрессия, развод и его последствия для детей, подростковый кризис, чувство вины и выгорание от родительства.

**Где обитают:** родительские чаты в Telegram, сообщества в VK («Мамы такого-то города»), Instagram (блоги о воспитании), тематические форумы, Pinterest.

### Взрослые с тревожностью и стрессом

**Кто:** мужчины и женщины 25–50 лет. Карьера, отношения, поиск баланса.

**Что их беспокоит:** постоянная тревога, панические атаки, выгорание на работе, бессонница, непонимание «что со мной не так».

**Где обитают:** Telegram-каналы о психологии и саморазвитии, YouTube (лекции, подкасты), профессиональные сообщества в VK, Instagram Reels с короткими советами.

### Пары в кризисе

**Кто:** пары 25–45 лет, вместе от 3 лет. Часто обращаются по инициативе женщины.

**Что их беспокоит:** повторяющиеся конфликты, утрата близости, мысли о разводе, неумение договариваться.

**Где обитают:** семейные форумы, Telegram-каналы об отношениях, Instagram-блоги психологов и коучей, подкасты о парах.

### Подростки (косвенный сегмент)

**Кто:** 13–17 лет. Обращаются редко, чаще через родителей.

**Что их беспокоит:** самооценка, буллинг, давление учёбы, отношения со сверстниками, конфликты с родителями, непонимание себя.

**Где обитают:** Telegram (каналы сверстников), TikTok/Reels, YouTube, анонимные форумы.

## 3. Growth Loops (петли роста)

### Петля 1: «Полезный контент → доверие → запись»

**Механика:** Пользователь находит статью в блоге через поиск → получает реальную пользу → доверяет эксперту → записывается на консультацию.

**Усилители:**
- SEO-оптимизация каждой статьи под конкретный поисковый запрос («как помочь ребёнку при разводе»)
- CTA в конце каждой статьи: «Разобрали общие принципы — на консультации разберём вашу конкретную ситуацию»
- Бесплатный лид-магнит: «5 упражнений для снижения тревоги» в обмен на подписку

**Метрика:** количество заявок с блога.

### Петля 2: «Соцсети → касание → сайт → запись»

**Механика:** Пользователь видит пост в Instagram/Telegram → узнаёт о существовании психолога → переходит на сайт → записывается.

**Усилители:**
- Три касания для прогрева: 1-й пост — проблема, 2-й — личная история, 3-й — приглашение
- Интерактив: опросы в Telegram, вопросы в сторис Instagram
- Кейсы (обезличенные): «Клиентка пришла с запросом X, через 8 сессий результат Y»

**Метрика:** переходы из соцсетей на сайт, конверсия в заявку.

### Петля 3: «Сарафанное радио → рекомендация → запись»

**Механика:** Клиент прошёл терапию → получил результат → рекомендует друзьям/коллегам → новые клиенты.

**Усилители:**
- Просьба о рекомендации после завершения курса сессий
- Карточка-визитка для пересылки в мессенджерах
- Партнёрства: гинекологи, педиатры, учителя — те, кто видит клиентов с психологическими запросами первыми

**Метрика:** доля клиентов «по рекомендации» (отслеживать при записи).

### Петля 4: «Статья блога → переупаковка в соцсети → возврат на сайт»

**Механика:** Статья на сайте → из неё делается 3–4 поста для соцсетей → каждый пост ведёт на полную статью → читатель попадает на сайт → видит другие статьи и предложение консультации.

**Усилители:**
- Каждая статья блога автоматически порождает контент на неделю для всех платформ
- Кросс-ссылки между статьями («читайте также»)
- Серии статей: 4–5 материалов на одну тему, объединённых в рубрику

**Метрика:** глубина просмотра сайта, время на сайте.

## 4. Маркетинговые идеи

### Идея 1: «Родительский чек-лист» — лид-магнит

**Суть:** Бесплатный PDF «10 признаков, что ребёнку нужна помощь психолога». Родитель оставляет email/Telegram → получает чек-лист → через 2 дня — приглашение на консультацию.

**Почему сработает:** Родители часто сомневаются «а нормально ли это?». Чек-лист снимает сомнения и мягко подводит к записи.

### Идея 2: Серия статей «5 признаков...»

**Суть:** Серия SEO-статей в блог:
- «5 признаков эмоционального выгорания»
- «5 признаков, что ребёнку нужен психолог»
- «5 признаков, что отношения в кризисе»
- «5 признаков, что тревога перестала быть нормой»

**Почему сработает:** Формат «признаки» — один из самых кликабельных в поиске. Человек узнаёт себя → хочет решения → запись.

### Идея 3: «Один день из практики» — Telegram-рубрика

**Суть:** Ежедневные короткие заметки в Telegram (500 знаков): обезличенный случай из практики, инсайт дня, наблюдение. Формат дневника.

**Почему сработает:** Создаёт эффект присутствия и доверия. Подписчики привыкают к ежедневному контакту → при появлении запроса идут к «своему» психологу.

### Идея 4: Партнёрство с «точками входа»

**Суть:** Договорённость с педиатрами, гинекологами, школьными учителями, HR-специалистами о рекомендации. Им даётся готовая визитка-ссылка для пересылки пациентам/сотрудникам.

**Почему сработает:** Люди приходят к психологу не из поиска, а когда кто-то, кому они уже доверяют, говорит «вам стоит поговорить с психологом». Врач/учитель — идеальный рекомендатель.

### Идея 5: Бесплатная 15-минутная консультация-знакомство

**Суть:** Предложить короткий созвон без оплаты, где человек рассказывает о запросе, а психолог объясняет, как будет строиться работа и отвечает на вопросы.

**Почему сработает:** Снимает главный барьер — страх неизвестности. Человек «пробует» психолога без риска → выше конверсия в платную сессию.

### Идея 6: «Вопрос недели» — интерактив в Instagram/Telegram

**Суть:** Раз в неделю подписчики присылают анонимные вопросы → психолог выбирает один и даёт развёрнутый ответ в посте/сторис.

**Почему сработает:** Вовлекает аудиторию, даёт контент на основе реальных запросов, показывает экспертизу. Люди видят ответ на чужой вопрос и узнают себя.

### Идея 7: Мини-курс в Telegram «7 дней спокойствия»

**Суть:** Бесплатный недельный марафон в Telegram-канале: каждый день — одно упражнение для снижения тревоги. В конце — приглашение на индивидуальную работу.

**Почему сработает:** Прогрев за 7 дней. Человек получает реальную пользу бесплатно → доверие растёт → часть участников конвертируется в клиентов.

### Идея 8: «Практики между сессиями» — рекомендация Vipassana

**Суть:** Рекомендовать клиентам и читателям блога бесплатные 10-дневные курсы медитации Vipassana (dhamma.org) как дополнительную практику для углубления самопознания между сессиями. Разместить ссылку на сайте как рекомендуемый ресурс.

**Почему сработает:**
- Vipassana учит наблюдать свои мысли и эмоции — это усиливает эффект терапии
- Бесплатные курсы по всему миру — доступный инструмент для любого клиента
- Позиционирует Анастасию как специалиста с целостным подходом (терапия + осознанность)
- Создаёт дополнительную ценность: клиент получает не только сессии, но и систему практик

**Где разместить:** страница «Как проходит консультация» → раздел «Что ещё может помочь», статья в блоге, FAQ.
