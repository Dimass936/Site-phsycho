# PROJECT.md — Сайт психолога Анастасии Палютиной

## О проекте

Многостраничный статический сайт для практикующего психолога **Анастасии Палютиной**.

**Формат работы:** онлайн-консультации
**Целевая аудитория:** взрослые, пары, подростки
**Специализации:** детская психология, отношения, стресс, тревожность, личностный рост, кризисные состояния

## Цели сайта

1. **Привлечение клиентов** — превращать посетителей в запись на консультацию
2. **Информирование** — рассказывать о методах работы и направлениях
3. **Доверие** — создавать образ профессионала через контент и дизайн

## Структура

| Страница | Назначение |
|----------|-----------|
| Главная | Первое впечатление: hero, направления, отзывы, CTA |
| Обо мне | Образование, подход, философия, фото |
| Услуги | 6 направлений с ценами и кнопками записи |
| Как проходит | 5 шагов процесса, FAQ по онлайн-формату |
| Блог | Статьи с фильтрацией по категориям |
| FAQ | 8 вопросов-ответов в аккордеоне |
| Контакты | Мессенджеры (Telegram, WhatsApp) + соцсети (Instagram, VK, Max) + форма записи |

## Технологии

- Статический HTML/CSS/JS (без фреймворков)
- Google Fonts: Inter + Playfair Display
- GitHub Pages + GitHub Actions (автодеплой)
- DeepSeek API для ИИ-маркетологов
