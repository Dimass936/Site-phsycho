## 1. Обзор проекта

Полнофункциональная платформа для частного психолога, объединяющая статический сайт-визитку, блог, систему автоматического контент-маркетинга и Telegram-бота с ИИ-интеграцией. Проект использует команду из **7 ИИ-агентов** (агентная архитектура) для автоматизации маркетинга и создания контента в стиле автора канала.

**Количественные показатели:**
- 8 156 строк кода
- 7 HTML-страниц (3 794 строк)
- 11 CSS-файлов (1 814 строк)
- 3 JS-модуля (196 строк)
- 7 Python-агентов (2 352 строк)
- 23+ git-коммитов

## 4. Уникальные достижения

### 4.1 Агентная архитектура для контент-маркетинга

Создана команда из **7 ИИ-агентов**, каждый со своей ролью:
- **CMO** → стратегия
- **Content Writer** → статьи
- **Telegram Agent** → контент-план
- **Telegram Bot** → интерфейс управления
- **Weekly Reporter** → аналитика
- **Second Brain** → интеграция с Obsidian
- **Style Learner** → анализ стиля

Агенты работают по цепочке через **Orchestrator** (`orchestrator.py`), запускаясь последовательно: CMO → Content Writer → Telegram Agent.

### 4.2 Самообучающаяся система стиля

Бот анализирует реальные посты из канала через DeepSeek API и создаёт гайд по стилю. При генерации нового контента гайд используется как часть system prompt — посты создаются в стиле автора канала.

### 4.3 Approval Flow с визуальным выбором

Уникальная механика утверждения постов:
1. Бот генерирует пост + 3 варианта ИИ-картинок
2. Администратор выбирает картинку (или загружает свою)
3. Может отредактировать текст и картинку комментарием
4. Нажимает «Опубликовать» → пост в канал

### 4.4 Интеграция с Obsidian («второй мозг»)

Проект интегрирован с персональной базой знаний Obsidian:
- Успешные и провальные посты сохраняются для анализа
- Стиль-гайд хранится в вики
- Агенты читают рекомендации из прошлых отчётов
- Каждая неделя улучшает качество контента

### 4.5 Вторник/пятница с авто-темами

Планировщик учитывает день недели: если бот генерирует пост во вторник — ссылается на пятницу, и наоборот. 109 тем загружены из Google Sheets контент-плана, фильтруются по категориям (например, «только детская психология»).

## 5. Интересные технические решения

### 5.1 Rate Limiter на файловой системе

Ограничение публикаций «раз в неделю» реализовано через `last_post.txt` — простое, но надёжное решение без базы данных.

### 5.2 Approval Queue через JSON-файл

Отложенные посты хранятся в `pending_posts.json`. При `/ok` первый пост из очереди публикуется, при `/skip` — удаляется. Очередь сохраняется между перезапусками бота.

### 5.3 Fallback для изображений

Если Pollinations.ai не успевает отдать картинку за 45 секунд — бот отправляет прямую ссылку вместо зависания. `read_timeout=45` + try/except.

### 5.4 Multi-admin система

Поддержка нескольких администраторов через запятую в .env: `TELEGRAM_USER_ID=707210809,1211845739`. Все команды доступны обоим.

### 5.5 Контекстный день недели

System prompt динамически учитывает `datetime.now().strftime("%A")` — если вторник, пост ссылается на пятницу, и наоборот. Без хардкода.

### 5.6 CSS Custom Properties как дизайн-система

30+ переменных в `:root`: цвета, типографика, отступы, тени, скругления, transition, z-index. Единая точка правки для всего сайта.

## 7. Выводы

Проект демонстрирует практическое применение:
- **Агентной архитектуры** — 7 ИИ-агентов, каждый с собственной ролью
- **Интеграции ИИ в реальный бизнес** — автоматизация контент-маркетинга для частного специалиста
- **Самообучающейся системы** — анализ стиля → гайд → улучшение качества
- **Полного цикла разработки** — от дизайн-системы до CI/CD и 24/7 хостинга
- **Zero-cost инфраструктуры** — все компоненты на бесплатных тарифах (GitHub Pages + Google Cloud Free Tier + DeepSeek API + Pollinations.ai)

**Реальный результат:** бот генерирует посты в стиле Анастасии, отправляет на утверждение, публикует в канал «Научусь летать» — полностью автоматически, дважды в неделю.
