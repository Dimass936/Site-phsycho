# REQUIREMENTS.md — Требования к маркетингу и контенту

## 1. Общие требования

Сайт психолога нуждается в регулярном контенте и каналах продвижения для привлечения клиентов.

### Целевые метрики
- Увеличение трафика на сайт
- Рост заявок на консультацию
- Узнаваемость бренда «Анастасия Палютина»

## 2. Контент для блога

### Требования к статьям
- **Темы:** детская психология, отношения, стресс, саморазвитие, тревожность, воспитание
- **Частота:** 1–2 статьи в неделю
- **Объём:** 1500–3000 знаков
- **Тон:** профессиональный, тёплый, без академизма
- **SEO:** каждая статья содержит мета-описание, ключевые слова, структуру H2/H3

### Формат статьи
1. Заголовок (привлекающий внимание)
2. Введение (почему это важно читателю)
3. Основная часть (2–3 подраздела)
4. Практические рекомендации
5. CTA — призыв записаться на консультацию

### Категории блога
| Категория | Примеры тем |
|-----------|------------|
| Дети | Страхи, агрессия, адаптация к школе, развод родителей |
| Отношения | Конфликты, коммуникация, близость, расставание |
| Стресс | Выгорание, панические атаки, тревожность, бессонница |
| Саморазвитие | Самооценка, границы, цели, синдром самозванца |

## 3. Контент для соцсетей

### Платформы и форматы

| Платформа | Тип контента | Частота |
|-----------|-------------|---------|
| **Telegram** | Посты 500–1000 знаков, опросы, личные заметки | 3–5 раз в неделю |
| **Instagram** | Карусели, рилс-сценарии, сторис, посты | 4–6 раз в неделю |
| **VK** | Статьи, посты, обсуждения | 3–4 раза в неделю |

### Требования к контенту
- Адаптирован под формат платформы (длина, визуал, хештеги)
- Завершается CTA (ссылка на сайт / запись)
- Визуал: спокойные пастельные тона (как на сайте)
- Включает личный опыт / кейсы (без нарушения конфиденциальности)

## 4. Email-рассылка (опционально)

- Приветственное письмо после записи
- Еженедельный дайджест статей блога
- Полезные материалы: чек-листы, упражнения

## 5. SEO-продвижение

### Ключевые слова (в разработке)
- Психолог онлайн
- Консультация психолога
- Детский психолог
- Семейный психолог
- Помощь при тревоге
- Психолог для подростков

### Технические требования
- Все страницы уже оптимизированы (OG, Schema.org, canonical, sitemap)
- Каждая статья блога получает мета-теги и ключевые слова

## 6. Роли ИИ-маркетологов

Для реализации требований нужны следующие агенты:

| Роль | Зона ответственности |
|------|---------------------|
| **Контент-стратег** | Контент-план, рубрикатор, календарь публикаций |
| **Копирайтер блога** | Статьи 1500–3000 знаков, SEO-оптимизация |
| **SMM-менеджер** | Посты для Telegram, Instagram, VK |
| **SEO-аналитик** | Ключевые слова, аналитика, оптимизация |
| **Редактор** | Проверка тона, стиля, единообразие бренда |

## 7. Интеграция с сайтом

- Статьи блога добавляются в `site/blog.html` (новые карточки)
- Обновления пушатся в GitHub → автодеплой на GitHub Pages
- Посты в соцсетях ссылаются на сайт и конкретные статьи
- Чат-бот (опционально) отвечает на частые вопросы и направляет на запись

## 8. Инструменты

- **DeepSeek API** — генерация контента (ключ: .env)
- **GitHub** — хранение и деплой контента
- **Соцсети** — публикация руками или через API
